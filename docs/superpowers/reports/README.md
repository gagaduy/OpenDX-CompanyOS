# Implementation Reports

This directory contains historical implementation and validation reports
produced while executing approved plans.

- `../specs/` defines approved behavior and architecture.
- `../plans/` defines implementation tasks and acceptance criteria.
- `reports/` records what an implementation run delivered and verified.

Reports are supporting evidence, not normative product or architecture
contracts. Current project status belongs in `docs/roadmap/mvp-status.md`, and
reproducible validation commands belong in `docs/build-from-source.md`.

Do not record secrets, access tokens, private customer data, machine-specific
credentials, or temporary public endpoints in reports.
